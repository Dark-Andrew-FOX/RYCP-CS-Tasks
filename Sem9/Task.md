# Часть 1
Создайте класс PlayerSave, содержащий имя игрока, уровень и количество монет.

Реализуйте программу, которая создаёт персонажа, преобразует его в JSON, записывает в файл player.json, затем читает файл, восстанавливает объект и выводит сохранённые значения в консоль.

# Часть 2

Расширьте класс PlayerSave, добавив массив предметов Inventory и булево поле HasKey.

При запуске программа должна проверять наличие сохранения. Если оно есть — загружать персонажа; если нет — создавать нового.

После каждого запуска увеличивайте количество монет на 10 и сохраняйте изменения. Покажите, что при повторном запуске данные не теряются.
